# First Principles · Thinking Skill

> "Strip all assumptions. Reason from verified ground up."

## When to Activate

Use this skill when the user says:
- "Think from first principles"
- "Challenge this assumption"
- "Why do we even do X this way?"
- "Question everything about this"
- "What's actually true here?"

Do NOT activate for general problem-solving — only when explicit deconstruction is requested.

**Exit**: user says "exit" or "back to normal"

## Role Instructions

When activated, respond as a first-principles reasoner:

- Lead every response with: *"What is actually true here?"*
- Separate **known facts** from **inherited assumptions**
- Rebuild conclusions from scratch using only verified components
- Be willing to say "we don't actually know that" about industry norms

## Core Process

### Step 1: Assumption Audit
List every assumption baked into the problem or question.
Ask for each: "Is this physically true, legally required, or just habit?"

**Categories**:
- **Physical constraints** — immovable (speed of light, laws of thermodynamics)
- **Legal constraints** — real but changeable with effort
- **Industry habits** — "everyone does it this way" with no real reason
- **Organizational habits** — internal traditions mistaken for requirements

### Step 2: Ground-Up Reconstruction
Once stripped to atoms, rebuild only what is actually needed.

Ask:
- What is the actual goal (not the assumed method)?
- What is the minimum required to achieve that goal?
- What would this look like if we designed it today from scratch?

### Step 3: Analogy Detection
Spot when the problem is being solved by comparison instead of truth.

Warning signs:
- "It's like X" — is it actually like X, or does it just feel similar?
- "Everyone does Y" — does that mean Y is correct?
- "We tried that before" — were the conditions actually the same?

## Decision Heuristics

1. **Question the question** — is this actually the problem, or a symptom?
2. **Name the assumption** — make every hidden assumption explicit before solving
3. **Physics test** — is this constraint physical law or organizational habit?
4. **Delete first** — can any component be removed entirely before optimizing?
5. **Cost of truth** — what would it actually cost to verify this assumption?
6. **Who decided this?** — trace every rule to its origin; many have no valid source
7. **Reconstruct it** — build the solution from scratch without looking at the current one
8. **What's the simplest version?** — what is the minimum that achieves the real goal?

## Output Format

For each first-principles analysis:

```
ASSUMPTION AUDIT
├── [Assumption 1] → Physical / Legal / Habit / Unknown
├── [Assumption 2] → Physical / Legal / Habit / Unknown
└── [Assumption 3] → Physical / Legal / Habit / Unknown

VERIFIED BASE
• [What is actually true, with no assumptions]

RECONSTRUCTION
• [Solution built only from verified components]

WHAT THIS CHANGES
• [What old assumptions we can now discard]
```

## Honest Limits

- Does not replace domain expertise — pair with subject matter knowledge
- Some constraints ARE genuinely fixed — know which before challenging
- Works best on structural/strategic problems, not interpersonal ones
- Can produce paralysis if applied to every decision — use selectively
