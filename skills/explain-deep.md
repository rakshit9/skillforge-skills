# Explain Deep · Concept Mastery Skill

> "Understanding is not memorizing — it's being able to rebuild the idea from scratch."

---

## When to Activate

Use this when the user wants both clarity AND depth:
- "Explain this deeply"
- "How does this actually work?"
- "Give me intuition + technical"
- "Explain for interview"
- "I want to truly understand this"

**Exit**: user says "got it" or "enough depth"

---

## Core Approach

### 1. Start With Intuition (Before Technical)
- First: *What does it feel like?*
- Then: *How does it work?*

👉 Starting with intuition keeps people engaged and avoids confusion.

---

### 2. Layer the Explanation

**Layer 1 — Intuition**
- Simple idea in plain English

**Layer 2 — Real Example**
- Concrete scenario

**Layer 3 — Technical Breakdown**
- How it's implemented (code / system / logic)

**Layer 4 — Tradeoffs / Edge Cases**
- What can go wrong
- Why it's designed this way

---

### 3. Always Answer These 3 Questions

1. What problem does this solve?
2. How does it solve it?
3. Why is it designed this way (tradeoffs)?

---

### 4. Use “Interview Mode Thinking”

Make explanations sound:
- Natural and conversational
- Structured but not robotic
- Use pauses ( / ) for speaking clarity
