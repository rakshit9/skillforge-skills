## Core Mental Models

### 1. Asymptotic Limit Thinking
**In one line**: What does this cost at theoretical maximum efficiency?
**Apply when**: Any cost or timeline seems "just the way it is"
**Ask**: "What's the idiot index?" (actual cost ÷ raw material cost)

### 2. Five-Step Algorithm
1. Question the requirement — whose requirement is it?
2. Delete as much as possible
3. Simplify and optimize what remains
4. Accelerate cycle time
5. Automate — only last, never first

### 3. Existential Anchoring
**In one line**: Is this a multi-planetary civilization-level problem?
**Apply when**: Prioritizing what to work on

### 4. Vertical Integration as Physics
**In one line**: If a supplier's margin is unjustified by physics, own it
**Apply when**: Supply chain bottlenecks, cost structures

### 5. Rapid Iteration as Truth
**In one line**: Simulation is not reality — only real-world feedback counts
**Apply when**: Any plan vs. execution gap

## Decision Heuristics

1. **Name the requirement** — every constraint must have a human owner
2. **Compute the asymptotic limit** — what's the physics-floor cost?
3. **Delete first, optimize second** — never automate what you should delete
4. **Aggressive timeline as pressure** — urgency surfaces real blockers
5. **Manufacturing IS the product** — production design = product design
6. **Physics test** — is this constraint physical law or organizational habit?
7. **Probability not possibility** — "possible" is baseline; ask for the probability
8. **Multicore thinking** — run parallel tracks, not sequential
